# 기획서 v2.5

재택·부업·알바 특화 무료 반응형 웹 채용 플랫폼

## 1. 프로젝트 개요

| 항목 | 내용 |
|------|------|
| 프로젝트명 | JobLink 365 |
| 목적 | 주부, 프리랜서, 알바 구직자를 위한 재택/단기/시간제 중심의 100% 무료 매칭 플랫폼 |
| 플랫폼 | 반응형 웹 (Desktop / Mobile) |
| 개발 방식 | Cursor IDE 기반 AI 협업 직접 개발 |
| 수익 모델 | Google AdSense 디스플레이 광고 기반 트래픽 수익 |

## 2. 인프라 및 기술 스택

- Frontend & Hosting: Vercel + Next.js (App Router), Tailwind CSS
- Backend & Database: Firebase (Firestore, Firebase Auth, Storage, FCM)
- 인증: 소셜 로그인(구글/카카오/네이버) + 국세청 사업자등록번호 조회 API
- DB Schema: 개발 진행 시 최적 구조로 자체 설계

## 3. 1차 MVP 개발 로드맵

| 단계 | 작업 영역 | 주요 구현 내용 |
|------|-----------|----------------|
| 1단계 | 프로젝트 세팅 & 레이아웃 | Next.js + Tailwind + Firebase 연동, Header / Main / Footer |
| 2단계 | 인증 (Auth) | 소셜 로그인, 유저 역할(`jobseeker`, `company`) |
| 3단계 | DB & 공고 작성 | 국세청 사업자 API 검증, 공고 등록 UI 및 Firestore 저장 |
| 4단계 | 공고 조회 & 지원 | 반응형 카드 리스트, 필터 검색, 이력서 업로드 지원 |
| 5단계 | 마이페이지 & 알림 | 지원 내역, 합/불 변경, 이메일/FCM |
| 6단계 | 애드센스 & 관리자 | 상단/인피드/상세 광고, 미승인 공고 검수 Admin |

## 4. 인증, 알림 및 광고 구조 (0원 운영)

- 기업 검증: 국세청 사업자등록번호 조회 API + 첫 공고 관리자 승인제
- 알림: FCM 웹 푸시 + 무료 이메일(Naver SMTP, lumi365과 동일 패턴)
- 애드센스: Header 하단 배너, 공고 리스트 인피드, 상세 하단, Footer 상단
