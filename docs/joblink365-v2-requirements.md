# JobLink 365 v2 요구사항

> 구직자 전용 크롤링 기반 채용 공고 aggregator  
> 시행 목표: joblink365.com 전면 개편

## 1. 서비스 방향

- **회원**: 구직자만 (이메일 + 비밀번호 + 닉네임)
- **채용 공고**: 외부 API 없이 크롤링 → 사이트에 표시 → 지원은 원문 사이트 새 창
- **제거**: 구인자, 이력서, 인재, 입사 지원, 면접 제안, 이용 주체(모드) 선택, Google·카카오·네이버 소셜 로그인
- **데이터**: 기존 회원·채용·이력서 데이터 전부 삭제 후 신규 가입만 허용

## 2. 상단 메뉴

| 상태 | 메뉴 |
|------|------|
| 로그인 전 | 로고, 채용 공고, 로그인, 회원가입 |
| 로그인 후 | 로고, 채용 공고, **내 채용 공고**, 닉네임(표시만), **마이페이지**, 로그아웃 |

- `/`(메인) = 채용 공고 목록과 동일
- 비로그인도 목록·검색·필터 조회 가능
- 내 채용 공고·마이페이지는 로그인 필수 → 비로그인 시 로그인으로 리다이렉트

## 3. 메인(채용 공고) 페이지

### 3.1 통합 검색

- 회사명, 직무, 지역 키워드 검색

### 3.2 빠른 필터

- 전체, 신입, 경력, 인턴

### 3.3 상세 필터 (버튼)

- 지역, 직무, 기업 규모, 고용 형태
- **수신 설정과 동일 항목·동일 이름** 사용

### 3.4 오늘의 신규 채용 공고

- 오늘 새로 수집된 공고만 **New** 표시
- 카드: 회사명, 공고 제목, 신입/경력/인턴, 지역, 마감일, 출처, New
- 첫 화면 **10건 + 더보기**
- "전체 신규 공고 보기" 링크

### 3.5 전체 목록

- 정렬: **최근 등록(수집) 상단**
- 페이지네이션: **10건 + 더보기** (전체·신규·내 채용 공고·찜한 공고 공통)
- 마감 공고: 목록에서 **숨김** (DB 유지)

## 4. 상세 페이지

- 크롤링한 상세 내용 표시
- **지원하기** → 원문 사이트 **새 창**
- 마감 공고 직접 URL 접근 시 **마감** 표시
- 하단 **댓글/답글**: 비로그인 읽기만, 로그인 후 작성
- 본인: **삭제만** (수정 없음)
- 관리자: 삭제·숨김
- **신고하기** 버튼

## 5. 내 채용 공고 (`/my-jobs`)

- 마이페이지 수신 설정 조건에 맞는 공고 목록
- 첫 화면 **10건 + 더보기**
- 로그인 필수

## 6. 마이페이지

- 회원 정보 (닉네임·이메일 **가입 후 변경 불가**)
- 비밀번호 변경
- **채용 공고 수신 설정**
- 이메일 수신 (마케팅 별도 선택)
- **찜한 공고** (10건 + 더보기, 최근 찜 순)
- **회원 탈퇴**
- 비밀번호 찾기/재설정 유지 (`/forgot-password`, `/api/find-password`, `/reset-password/confirm`)

### 6.1 채용 공고 수신 설정

1. **수신 여부**: 채용 공고 이메일 받기 / 받지 않기
2. **채용 형태** (복수): 신입, 경력, 인턴, 계약직, 기타
3. **관심 직무** (복수): IT·개발, 기획·PM, 디자인, 마케팅·광고, 영업·판매, 경영·사무, 생산·제조, 연구·개발, 금융·회계, 교육, 서비스·고객 관리, 기타
4. **희망 지역** (복수): 서울, 경기, 인천, 부산, 대구, 광주, 대전, 울산, 세종, 강원, 충북, 충남, 전북, 전남, 경북, 경남, 제주, 재택
5. **기업 규모** (복수): 대기업, 중견기업, 중소기업, 스타트업, 공공기관, 외국계

## 7. 회원가입

- 이메일, 비밀번호, 닉네임
- 닉네임·이메일 **중복 확인** 필수 (가입 시)
- 필수 약관 동의, 마케팅 수신 선택

## 8. 이메일 발송

- 매일 **9시** (KST)
- 조건 맞는 공고 **10건** + 하단 **내 채용 공고 더보기** 링크
- 조건에 맞는 공고 없으면 "새 공고가 없습니다" + 사이트 링크

## 9. 크롤링

- 자동 수집: **8시, 12시, 18시** (KST) — 메일 9시는 8시 수집 후
- 출처별 **별도 표시** (중복 합치지 않음)
- 1차: 일부 대기업 시범 → 최종: 대기업·중견·채용 사이트·대학

## 10. 관리자

- 대시보드, 회원 관리, 문의 관리, 크롤링 현황, 이메일 발송 내역, 댓글·답글 관리
- 지정 관리자 이메일만 접근 (기존 방식 유지)

## 11. 기타

- 광고: `AdSlot` 플레이스홀더 유지
- 하단 문의하기 유지
- 이용약관·개인정보처리방침 개편 내용으로 수정

## 12. Firestore 컬렉션 (신규)

| 컬렉션 | 용도 |
|--------|------|
| `crawledJobs` | 크롤링 공고 |
| `jobAlertPrefs` | 회원별 수신 설정 (`userId` 문서 ID) |
| `jobBookmarks` | 찜 (`userId_jobId` 또는 하위 컬렉션) |
| `jobComments` | 공고 댓글·답글 |
| `crawlRuns` | 크롤링 실행 로그 |
| `emailDigests` | 이메일 발송 내역 |

## 13. 구현 단계

1. 요구사항 문서 + 데이터 모델 + API
2. 헤더·메인·상세·내 채용 공고 UI
3. 이메일 인증·회원가입·마이페이지
4. 크롤러 스켈레톤 + 시범 데이터
5. 이메일 cron + 관리자 화면
6. 약관·개인정보 개편
