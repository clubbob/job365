    확인방법 : Adobe PDF 뷰어로 열람을 하였을때

                  표시될 겁니다.

2. 업로드 PDF에 수정패스워드가 설정되어있는 경우 처리 불가
    확인방법 : Adobe PDF 뷰어로 열람한 후 아래 메뉴에서 확인
                  파일 > 속성 > 문서속성 화면의 보안탭을 클릭 후 보안방법이
                  [보안 사용 안함]이라고 표시되어 있는 지을 확인 할 것

    확인방법 : 각사의 DRM정책을 바탕으로 해제해서 업로드 할 것

4. 업로드가 안되는 경우
    각사 내부 네트워크 환경 확인 및 브라우저를 바꿔서 진행할 것
